B. Things We Should NOT Implement

1. F-06 Automated SMS Pickup Alerts: Do not integrate Twilio or any messaging gateway.
2. F-07 External Supply Chain Sync: Do not attempt to pull data from supermarket databases; all inventory is manually inputted.
3. F-08 Automated System Reporting: Do not build graphing/analytics dashboards for grant applications.
4. F-09 Client Pickup Scheduling: Clients cannot pre-book specific hamper collection times.
5. SQL Databases: The SRS strictly mandates JSON file storage (Section 4.5). Do not use SQLite, PostgreSQL, or SQLAlchemy.
